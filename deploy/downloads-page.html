Get SnappyConnect

The SnappyHires calling app — pick your device. Sign in with the account your admin created for you.

📱 iPhone / iPad

  1. Install TestFlight from the App Store (Apple's official test-app installer).
  2. Then tap the button below and choose Install.
Get for iOS

🤖 Android

Download APK

Open the downloaded file to install. If Android warns about unknown apps, allow installs from your browser for this one file — the app comes only from this official page.

💻 Web (any computer)

Open the web app

Nothing to install — works in Chrome or Edge. Allow the microphone when asked. Tip: in Chrome, ⋮ menu → Cast, save and share → Install page as app — it gets its own icon and window like a real app.

🧩 Chrome extension (click-to-call)

Adds a call button next to phone numbers on any website.

Download extension
  1. Unzip the downloaded file.
  2. Open chrome://extensions, switch on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped folder.
  4. Click the SnappyConnect icon in the toolbar and sign in.

Need an account or a password reset? Ask your admin, or use “Forgot password” on the sign-in page.
